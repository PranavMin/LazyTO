# Kiosk module hook table (kiosk/tools/build_module.py).
# One patch per line, applied to the VANILLA Melee 1.02 DOL in RAM by the loaders
# (the LazyTO Nintendont kernel, or the Dolphin development setup) after the module blob is copied in:
#   ptr    <addr> <module symbol>   write the symbol's address at addr
#   branch <addr> <module symbol>   write "b <symbol>" at addr (function hijack)
#   word   <addr> <hex>             write a literal 32-bit word
# Addresses are vanilla (melee/config/GALE01/symbols.txt); the builder verifies each
# against melee/orig/GALE01/sys/main.dol where noted.

# mnmain.c: menu light colour by kind - the Trophies row (kind 3) maps to
# colour 2, green. mn_8022C010 is inlined into both real users (the light
# GObj's create mn_8022C304 and its per-frame lerp fn_8022C128), each with its
# own jump table in .data; the out-of-line copy is only reached from one other
# bl (0x8022E6A0). Kind 3's jump-table entry is pointed at the "colour 0"

# to a module replacement with the same mapping.
word   0x803EBA44 0x8022C190                # fn_8022C128 table[3] -> colour 0 case (was 0x8022C1A0, colour 2)

# gm_1A3F.c preloadState: the SIS text pool each scene gets (HSD_SisLib_803A6048).
# GS_MENU falls in the default case, 0x4800 = 18 KB, which the kiosk's set list
# (four text objects, ~100 entries with the rounded panels) exhausts - the
# allocator's "Memory Empty" OSPanic halts the CPU (seen 2026-09-25). The
# operand is an li immediate, which is SIGN-EXTENDED: 0x7800 (30 KB) is the
# largest size a single li can express (0xC000 became -16 KB and panicked at
# boot). The CSS case (0x801A3F9C, 0x2400) is left alone: the CSS overlay is a
# handful of entries.
word   0x801A3FA8 0x38607800                # li r3, 0x7800 (was li r3, 0x4800)
# The CSS case gets headroom too: the CSS overlay is three lines, but each now
# has a shadow and the score line a rounded panel (three text objects).
word   0x801A3F9C 0x38604800                # li r3, 0x4800 (was li r3, 0x2400)
