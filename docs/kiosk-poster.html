How to play your set

Pick your set, say who is who, play. Games are scored automatically.

1 Set list
2 Character select
3 Stage select
4 Play — the game scores itself
1 Set list

Find your set and pick it.

↑↓
Move up / down
LR
Filter by first letter of a tag
X
Jump to the set this setup is playing
A
Start the set
Z
Friendlies
Y
Refresh the list
B
Back to the main menu

No sets? Press Y. Still none? Tell the TO.

2 Character select

First: the player named on the left holds L + R.

L+R
I am the player named first (hold 1 s)
Corrections only — hold Z + flick the C-stick
Z+C◀
Give the left player a game
Z+C▶
Give the right player a game
Z+C▼
Undo the last game
Z+C▲
End the set (hold 1 s)
Z+X
Handwarmer (not scored)
↑↓
D-pad: rumble on / off for your port
START
Go to stage select
B
Back to the set list
3 Stage select
X
Strike the stage
Z
Bring back all struck stages
A
Pick the stage
B
Back to character select

After the game the score updates by itself.

It says SCORE BY HAND or SCORE IT MANUALLY? Give the winner the game with Z + C-stick.

Wrong set started, or a score you can't fix with undo? Get the TO before ending the set. LazyTO
