How to play your set

The setup reports your bracket set to start.gg for you. Find your set, pick your tag, play: each game is scored automatically when it ends. The controller binds are there to fix mistakes. Any port can use them.

3 Stage select

Strikes clear every time you come back to this screen, so strike fresh for each game (loser of the last game picks, as usual).

After the game you land back on character select with the score already updated (GAME 2 TO MANGO). Quitting with L+R+A+Start is a no contest and is not scored.

What the bottom of the screen means

MANGO P1  2 - 1  P3 ZAIN the score, in the banner under MELEE / VS (where the game normally names the mode), with the port each player's tag is on
HANDWARMER NEXT - NOT SCORED at the top: the next game won't count (armed because someone wasn't ready yet)
GAME 2 TO MANGO auto-scored  ·  PICK A TAG TO AUTO-SCORE nobody picked a tag, score by hand
SCORE SENT (green) start.gg has it  ·  SENDING... wait  ·  SEND FAILED (red) flick again, or tell the TO
